`floppy.svg` содержит `symbol` с идентификатором `floppy`. Обе иконки дискеты подключаются через `<use href="./svg/floppy.svg#floppy">`.

`favicon.svg` — векторный фавикон из предоставленного макета.

Сердца находятся инлайново в `index.html`: отдельные пути `core`, `main-body`, `contour` и `sparks` нужны для CSS-анимаций.
